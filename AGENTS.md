# Agent instructions: pqc-mtls-management-api

These bind every AI coding agent (Claude Code, Codex, Cursor, Copilot and any other) and every
human contributor in this repository.

1. **Read the project's engineering rules in full before your first change.** They live in one
   place, the gateway repository:
   - `../pqc-mtls-gateway/ENGINEERING-RULES.md` when it is checked out beside this one;
   - otherwise https://github.com/PQC-RA/pqc-mtls-gateway/blob/main/ENGINEERING-RULES.md

   If you can read neither, stop and say so. Do not work from memory.
2. Answer the PR checklist at the end of the rules in every PR description.
3. Findings, ADRs and the measured numbers live in the project vault (private). If you have it,
   read its `CLAUDE.md` before citing a number or proposing a design change.
